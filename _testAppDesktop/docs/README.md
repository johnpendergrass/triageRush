# Desktop Demo Documentation

These documents describe the isolated `_testAppDesktop` pre-production demo.
They explain the decisions made before desktop interface work begins.

Read in this order:

1. [Purpose and boundaries](purpose-and-boundaries.md)
2. [State and code structure](state-and-code-structure.md)
3. [Current assets, data, and next work](current-assets-data-and-next-work.md)
4. [Coach and Patient Review panel](coach-and-patient-review-panel.md)

The desktop demo is an experiment used to settle the final desktop design
before production game development. It is not the production application, and
its current structure should not be treated as an irreversible production
architecture.
