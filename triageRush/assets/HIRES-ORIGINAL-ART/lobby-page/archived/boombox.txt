The HTML prototype uses a minimum 44 x 44 CSS-pixel tap target centered over
each button. POWER highlights red; MUSIC and UI highlight green. Each target
currently toggles its own highlight/dehighlight state only.

The lower chrome buttons, knobs, and equalizer-style display are decorative.
There is no in-app volume control. Device/browser volume controls overall
loudness. The tuner display is fixed artwork reading 98.1 FM.

Classical KING stream:
  https://classicalking.streamguys1.com/KING-FM-128KAAC

POWER starts/stops the radio. MUSIC pauses/resumes the stream while powered.
UI is reserved for app sound effects and is visual-only in the demo. Playback
must start from a user tap; do not autoplay.
