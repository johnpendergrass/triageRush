# Patient CRUD App

Reserved for a future local patient creation and CRUD pipeline. This
administrative tool will not be part of the public triageRush application.

Its `anchor-images/` and `schema/` folders support patient creation,
validation, and editing. Approved patient JSON and final patient images belong
in the shared `patient-data/` library.

The parenthetical folder suffix is a temporary visual reminder that this is a
standalone local tool. Its final folder name will be selected when development
on the CRUD pipeline resumes.
