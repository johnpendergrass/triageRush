# Project Documentation

This folder owns documentation about the triageRush repository as a whole.

- `development/` records project-level decisions, migrations, handoffs, and
  history.
- `technical/` describes the current repository architecture, deployment, and
  boundaries between the public app, patient library, prototype, and local
  administrative tooling.

Game-specific documentation belongs under `../triageRush-app/docs/`.
Patient-CRUD documentation will belong with that standalone application when
its development resumes.
