### Approved item 12 navigation

John added item 12 using decisive “This will change” language. It was therefore
treated as an approved change and incorporated consistently:

- After Start Shift, GAME is the only active primary view.
- Quit Game confirms, discards the active shift without review, and opens HOME.
- Stop Game finalizes the shift and immediately opens SHIFT REVIEW.
- Timer expiry follows the same review-finalization path as Stop Game.
- SHIFT REVIEW's only primary-view action is Return to Lobby.
- HOME has settings and Start Shift only. It has no Resume Shift, active-lobby,
  or Return to Game state.
- SHIFT REVIEW has no Return to Game or direct New Shift action.
- A later Start Shift always creates a new shift.

To preserve mobile interruption safety without violating that navigation, a
valid persisted active snapshot may recover automatically and directly into
GAME after reload. It never creates a player-visible Resume Shift state. Quit,
stop, and completed-review Return to Lobby clear the recovery snapshot.
