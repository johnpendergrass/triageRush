## Historical-use rules

- Preserve historical wording and timestamps.
- Do not edit an old document to make it agree with the current application.
- Use archive material to understand rationale, alternatives, and development
  history.
- Some historical links retain paths from earlier repository layouts. When one
  no longer resolves, search the archive by the linked filename or subject.
- When an archived statement conflicts with a current numbered document, the
  current document wins.
- Before materially revising a stable current document, place a timestamped
  snapshot in the matching numbered archive folder.
