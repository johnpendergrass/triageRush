- Background dimensions: 604 x 1680 raster pixels

transparent, allowing them to sit over the patient-panel background without
rectangular remnants from the source mockup.

IMPLEMENTATION NOTES
- Treat these positions as mockup-alignment starting points, not final game
  constants, until the complete patient-column HTML layout is visually tested.
- Anchor overlays to the 604 x 1680 patient-panel coordinate system.
- When the complete game is scaled, scale the whole 360 x 640 canvas uniformly.
- Do not independently stretch an overlay in only one direction.
- Runtime text should remain HTML, not be baked into these images.
- The visual three-dot button in the clipboard is artwork; place a semantic
  HTML button over it with the same bounds for keyboard and touch interaction.
