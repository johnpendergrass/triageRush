# Prototype Reference

This folder documents the preserved interactive prototype at `_testApp/`
for use while building the production triageRush application.

Start with:

[2026 0727 1146 testApp visual and interaction specification.md](2026%200727%201146%20testApp%20visual%20and%20interaction%20specification.md)

The specification is descriptive, not automatically prescriptive. It records
what the prototype does, which values are deliberate, and which rules remain
provisional. The prototype source remains the exact authority for prototype
behavior:

- `_testApp/index.html`
- `_testApp/styles.css`
- `_testApp/app.js`

When the prototype changes materially, update the dated specification or add a
newer dated revision. Production decisions promoted from the prototype belong
in focused current documents one level above this folder.
