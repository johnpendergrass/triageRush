KING-FM on iOS — what actually works

Tap each test, listen, and read the line under it. Each one plays for about 5 seconds. SIGNAL is measured from the audio graph: a stream that plays but reads 0.000 is being silenced by CORS.

1. Plain element

No CORS, no Web Audio — what the game falls back to today. Expect: plays, at full volume, and no volume control.

2. crossOrigin only

Asks for CORS but does NOT route through Web Audio. If this fails, CORS is the problem. If it plays, CORS is fine and the routing is what iOS refuses.

3. crossOrigin + Web Audio gain

Exactly what the game tries first. This is the one that refused on the phone. If it plays here, the slider below should change its volume — which is the whole prize.

Gain 0.06

4. Web Audio gain, NO crossOrigin

Routed but without asking for CORS. Expect it to play while SIGNAL reads 0.000 — that is what "silently tainted" looks like, and it confirms the measurement is meaningful.

5. Other KING-FM mounts, routed

Same as test 3 against the station's other streams. If any ONE of these plays with signal, the game can switch to it and iOS gets its volume control back.
